## 🛠️ How to Use

### 1. **Direct Navigation**
```javascript
// In your component
navigateTo('/RoninNetwork')
```

### 2. **Programmatic Access**
```javascript
// Get all network pages
const evmNetworks = [
  'Ronin', 'ImmutableZkEVM', 'Beam', 'Oasys',
  'PolygonZkEVM', 'Boba', 'Metis', 'Aurora',
  // ... etc
];

// Navigate to specific network
const goToNetwork = (network) => {
  navigateTo(`/${network}Network`);
};
```

### 3. **URL Parameters**
```
http://localhost:3000/RoninNetwork
http://localhost:3000/CeloNetwork?userID=123
```

## 📊 Wallet Generation API

All networks use the same backend endpoint:

```javascript
POST /api/v1/Wallets/generateEVMWallet

Body:
{
  userID: "user123",
  network: "Ronin", // Network key from config
  walletName: "My Ronin Wallet"
}

Response:
{
  success: true,
  walletId: "wallet_id",
  address: "0x...",
  network: "Ronin",
  chainId: 2020,
  message: "Ronin wallet generated successfully!"
}
```

## 🎨 Adding Custom Navigation

If you want to add links to these networks in your UI:

### Example 1: Dropdown Menu
```vue
<n-dropdown :options="networkOptions" @select="handleNetworkSelect">
  <n-button>Select Network</n-button>
</n-dropdown>

<script>
const networkOptions = [
  { label: '🎮 Gaming Networks', key: 'gaming-header', type: 'header' },
  { label: '⚔️ Ronin', key: 'Ronin' },
  { label: '🎯 Immutable zkEVM', key: 'ImmutableZkEVM' },
  // ... more networks
];

const handleNetworkSelect = (key) => {
  navigateTo(`/${key}Network`);
};
</script>
```

### Example 2: Search Interface
```vue
<n-input v-model:value="searchQuery" placeholder="Search networks..." />
<n-list v-if="filteredNetworks.length">
  <n-list-item v-for="network in filteredNetworks" :key="network.key">
    <n-button text @click="navigateTo(`/${network.key}Network`)">
      {{ network.icon }} {{ network.name }}
    </n-button>
  </n-list-item>
</n-list>
```

### Example 3: Category Tabs
```vue
<n-tabs>
  <n-tab-pane name="gaming" tab="🎮 Gaming">
```
